# Генерация 3D-моделей мебели

Документ описывает систему конфигурации и генерации 3D-моделей модульной кухонной мебели на основе `build.js`.

---

## Общая архитектура

Система представляет собой конфигуратор кухонной мебели. Каждый предмет мебели описывается декларативным объектом конфигурации, который затем интерпретируется рендерером для построения 3D-модели.

Ключевые компоненты:
- **Unit-конфигурации** — описание каждого предмета мебели (форма, размеры, материалы)
- **Система опций** — иерархические группы параметров с типизацией
- **Выражения** — динамические вычисления размеров (`=({%100}-50)`)
- **Каталожные коды** — привязка к материалам и артикулам

---

## Структура Unit-конфигурации

Каждый предмет мебели описывается следующим объектом верхнего уровня:

```js
{
    uid: "stol-3yashika",           // Уникальный идентификатор
    catalogCode: "stol-3yashika",   // Код для заказа/каталога
    level: a.LEVEL_BOTTOM,          // Уровень расположения
    title: "Стол №3ЯК (3 ящика)",  // Отображаемое название
    widthText: "400 - 600 мм",      // Текст ширины для UI
    depthText: "600 мм",            // Текст глубины для UI
    heightText: "870 мм",           // Текст высоты для UI
    image: "/static-files/unit/...",// Превью-изображение
    options: [...]                   // Массив групп параметров
}
```

---

## Константы уровней (`LEVEL_*`)

Определяют вертикальное расположение секции в кухонном гарнитуре:

| Константа      | Описание                       |
|----------------|--------------------------------|
| `LEVEL_BOTTOM` | Нижние напольные секции        |
| `LEVEL_TOP`    | Верхние навесные секции        |
| `LEVEL_TALL`   | Высокие пеналы (в полный рост) |

---

## Типы опций (`OPTION_TYPE_*`)

Каждый параметр внутри groups имеет тип:

| Тип                       | Описание                                                   |
|---------------------------|------------------------------------------------------------|
| `OPTION_TYPE_HIDDEN_NUMBER` | Скрытое числовое значение (используется рендерером)      |
| `OPTION_TYPE_HIDDEN_TEXT`   | Скрытое текстовое значение (код класса, каталога)        |
| `OPTION_TYPE_RADIOBUTTON`   | Выбор из вариантов (ширина корпуса и т.п.)               |
| `OPTION_TYPE_JSON`          | Сложный JSON-объект (фасады, ножки, полки, цоколи и др.) |

---

## Группы опций (`options[]`)

Опции организованы в именованные группы (`isGroup: true`). Порядок отображения задаётся полем `sort`.

### `sizes` — Общие габариты секции

```js
{
    id: "sizes", isGroup: true,
    options: [
        { id: "height", value: 870, type: OPTION_TYPE_HIDDEN_NUMBER },
        { id: "depth",  value: 600, type: OPTION_TYPE_HIDDEN_NUMBER }
    ]
}
```

Хранит внешние габариты секции (высота + глубина). Ширина задаётся в группе `corpus`.

---

### `corpus` — Корпус секции

Основная группа, описывающая геометрию и материал корпуса:

```js
{
    id: "corpus", isGroup: true,
    options: [
        { id: "catalogCode",    value: "N_FOD3", type: OPTION_TYPE_HIDDEN_TEXT },
        { id: "width",          type: OPTION_TYPE_RADIOBUTTON, defaultValue: "450",
          items: [
              { id: "400", title: "400 мм" },
              { id: "450", title: "450 мм" },
              { id: "500", title: "500 мм" },
              { id: "550", title: "550 мм" },
              { id: "600", title: "600 мм" }
          ]
        },
        { id: "height",         value: 720,  type: OPTION_TYPE_HIDDEN_NUMBER },
        { id: "depth",          value: 478,  type: OPTION_TYPE_HIDDEN_NUMBER },
        { id: "thickness",      value: 16,   type: OPTION_TYPE_HIDDEN_NUMBER },
        { id: "backThickness",  value: 4,    type: OPTION_TYPE_HIDDEN_NUMBER },
        { id: "boxes",          value: [],   type: OPTION_TYPE_JSON }
    ]
}
```

| Параметр        | Описание                                    |
|-----------------|---------------------------------------------|
| `catalogCode`   | Артикул материала/отделки (напр. `N_FOD3`)  |
| `width`         | Ширина — выбирается пользователем           |
| `height`        | Высота корпуса (без ножек и столешницы)     |
| `depth`         | Глубина корпуса                             |
| `thickness`     | Толщина боковых стенок (обычно 16 мм)       |
| `backThickness` | Толщина задней стенки (обычно 4 мм)         |
| `boxes`         | Конфигурация внутренних ящиков              |

---

### `className` — Класс объекта

Определяет тип секции, который выбирает соответствующий рендерер/builder:

```js
{ id: "className", value: a.CLASSNAME_BOTTOM_UNIT_NORMAL, type: OPTION_TYPE_HIDDEN_TEXT }
```

#### Нижние секции (`CLASSNAME_BOTTOM_UNIT_*`)

| Константа                              | Тип секции                        |
|----------------------------------------|-----------------------------------|
| `CLASSNAME_BOTTOM_UNIT_NORMAL`         | Стандартная нижняя секция         |
| `CLASSNAME_BOTTOM_UNIT_SINK`           | Секция под мойку                  |
| `CLASSNAME_BOTTOM_UNIT_OVEN`           | Секция под духовой шкаф           |
| `CLASSNAME_BOTTOM_UNIT_DISHWASHER`     | Секция под посудомоечную машину   |
| `CLASSNAME_BOTTOM_UNIT_SINK_OPENED`    | Открытая секция под мойку         |
| `CLASSNAME_BOTTOM_UNIT_FULL_LENGTH_SIDEWALL` | С полной боковой стенкой   |
| `CLASSNAME_BOTTOM_UNIT_BAR_STAND`      | Барная/стоечная секция            |
| `CLASSNAME_BOTTOM_UNIT_PILASTER`       | Пилястра                          |
| `CLASSNAME_BOTTOM_ANGLE_UNIT_*`        | Угловые секции (разные типы)      |

#### Верхние секции (`CLASSNAME_TOP_UNIT_*`)

| Константа                          | Тип секции                    |
|------------------------------------|-------------------------------|
| `CLASSNAME_TOP_UNIT_NORMAL`        | Стандартная верхняя секция    |
| `CLASSNAME_TOP_UNIT_PILASTER`      | Верхняя пилястра              |
| `CLASSNAME_TOP_UNIT_SHELF_FIGURED` | Декоративная полка            |

#### Пеналы

| Константа                      | Тип секции             |
|--------------------------------|------------------------|
| `CLASSNAME_PENAL_UNIT_WARDROBE`| Шкаф-пенал (гардероб) |

### `facades` — Фасады (двери и декоративные панели)

Массив объектов, каждый описывает один фасадный элемент:

```js
{
    id: facades,
    type: OPTION_TYPE_JSON,
    value: [
        {
            id: 0,                                      // Индекс фасада
            initSizes: { width: "%100", height: "430" },// Исходные размеры
            gap: { bottom: 2, left: 2, right: 2, top: 0 }, // Зазоры
            geometryType: a.GEOMETRY_TYPE_SQUARE,       // Форма
            sideType: a.SIDE_TYPE_DEFAULT,              // Сторона секции
            number: 0,                                  // Порядковый номер двери
            align: { x: a.ALIGN_CENTER, y: a.ALIGN_BOTTOM }, // Выравнивание
            margin: { x: 0, y: -145, z: 0 },           // Сдвиг
            modelType: a.FACADE_MODEL_TYPE_PLANE,       // Тип модели
            calculateSizes: { width: "%100", height: "%100" }, // Расчётные размеры
            calculateType: a.FACADE_CALCULATE_NONE,     // Метод расчёта
            functionalType: "threeBoxes",               // Функциональный тип
            openType: a.FACADE_OPEN_TYPE_BOX,           // Тип открывания
            groupId: 1,                                 // Группа анимации
            handle: {                                   // Ручка
                id: 0,
                align: { x: a.ALIGN_CENTER, y: a.ALIGN_TOP },
                location: a.HANDLE_TYPE_HORIZONTAL
            }
        }
    ]
}
```

#### Размеры фасадов

| Значение  | Смысл                                   |
|-----------|-----------------------------------------|
| `"%100"`  | 100% ширины/высоты корпуса              |
| `"430"`   | Абсолютное значение в мм                |
| `"=%100/2"` | Выражение (половина ширины)           |

#### Типы геометрии (`GEOMETRY_TYPE_*`)

| Константа              | Описание           |
|------------------------|--------------------|
| `GEOMETRY_TYPE_SQUARE` | Прямоугольный фасад|

#### Типы открывания (`FACADE_OPEN_TYPE_*`)

| Константа                        | Описание                         |
|----------------------------------|----------------------------------|
| `FACADE_OPEN_TYPE_BOX`           | Открывается как ящик (выдвижной) |
| `FACADE_OPEN_TYPE_VERTICAL_PIVOT`| Вертикальная петля (распашная)   |

#### Типы модели (`FACADE_MODEL_TYPE_*`)

| Константа                   | Описание                       |
|-----------------------------|--------------------------------|
| `FACADE_MODEL_TYPE_PLANE`   | Плоский фасад без глубины      |
| `FACADE_MODEL_TYPE_DEFAULT` | Стандартный объёмный фасад     |

#### Стороны (`SIDE_TYPE_*`)

| Константа          | Описание      |
|--------------------|---------------|
| `SIDE_TYPE_DEFAULT`| Передняя (по умолчанию) |
| `SIDE_TYPE_FRONT`  | Фронт         |
| `SIDE_TYPE_BACK`   | Зад           |
| `SIDE_TYPE_LEFT`   | Левая сторона |
| `SIDE_TYPE_RIGHT`  | Правая сторона|
| `SIDE_TYPE_NONE`   | Без стороны   |

#### Функциональные типы фасадов (`functionalType`)

Строковые идентификаторы, задающие логику работы двери:

- `"pivotDoor"` — распашная дверь
- `"threeBoxes"` — ящик из трёх фасадов
- прочие строки — кастомная логика рендерера

### `legs` — Ножки

Четыре ножки по углам корпуса:

```js
{
    id: "legs", type: OPTION_TYPE_JSON,
    value: [
        { id: 0, initPosition: { x: "50",             z: "50" } },           // Передний левый
        { id: 0, initPosition: { x: "=({%100}-50)",   z: "50" } },           // Передний правый
        { id: 0, initPosition: { x: "=({%100}-50)",   z: "=({%100}-50)" } }, // Задний правый
        { id: 0, initPosition: { x: "50",             z: "=({%100}-50)" } }  // Задний левый
    ]
}
```

#### Система выражений для позиций

| Выражение           | Смысл                                      |
|---------------------|--------------------------------------------|
| `"50"`              | Отступ 50 мм от края                       |
| `"{%100}"`          | Ссылка на 100% размера (ширину или глубину)|
| `"=({%100}-50)"`    | Вычисление: (размер - 50), правый/задний край |

Формат `={expression}` означает вычисляемое выражение. `{%100}` — специальный токен, заменяемый текущим размером оси.

---

### `tabletops` — Столешницы

```js
{ id: "tabletops", type: OPTION_TYPE_JSON, value: [{ id: 0 }] }
```

Добавляется к нижним секциям. `id: 0` — референс на текущий выбранный материал столешницы.

---

### `aprons` — Стеновые панели (фартук)

```js
{
    id: "aprons", type: OPTION_TYPE_JSON,
    value: [
        { id: 0, positionType: a.SIDE_TYPE_BACK },
        { id: 0, positionType: a.SIDE_TYPE_LEFT },
        { id: 0, positionType: a.SIDE_TYPE_RIGHT }
    ]
}
```

Панели размещаются с трёх сторон (зад, лево, право) для нижних секций.

---

### `plinths` — Цоколь

```js
{
    id: "plinths", type: OPTION_TYPE_JSON,
    value: [
        { id: 0, positionType: a.SIDE_TYPE_BACK },
        { id: 0, positionType: a.SIDE_TYPE_LEFT },
        { id: 0, positionType: a.SIDE_TYPE_RIGHT },
        { id: 0, positionType: a.SIDE_TYPE_FRONT },
        {
            id: 0,
            positionType: a.SIDE_TYPE_FRONT,
            margin: { y: 90 },
            initSizes: { length: "=({%100}-32)", width: 90 },
            canUnion: false
        }
    ]
}
```

Поддерживает кастомные размеры через `initSizes` и выражения. `canUnion: false` — запрет объединения с соседними цоколями.

---

### `corners` — Угловые накладки

```js
{
    id: "corners", type: OPTION_TYPE_JSON,
    value: [
        { id: 0, positionType: a.SIDE_TYPE_BACK },
        { id: 0, positionType: a.SIDE_TYPE_LEFT },
        { id: 0, positionType: a.SIDE_TYPE_RIGHT }
    ]
}
```

---

### `shelves` — Полки

```js
{
    id: "shelves", type: OPTION_TYPE_JSON,
    value: [
        {
            id: 0,
            length: "%100",
            depth: "=({%100}-45)",
            initPosition: { y: "=(({%100}/6)*5)" },
            type: a.SHELF_TYPE_HORIZONTAL,
            thickness: 16,
            fixed: true
        }
    ]
}
```

| Параметр       | Описание                              |
|----------------|---------------------------------------|
| `length`       | Длина полки (`%100` = вся ширина)     |
| `depth`        | Глубина полки (часто глубина - отступ)|
| `initPosition` | Начальная вертикальная позиция        |
| `fixed`        | Полка не передвигается пользователем  |
| `type`         | Тип полки (`SHELF_TYPE_HORIZONTAL`)   |

---

### `rods` — Штанги (для одежды)

```js
{
    id: "rods", type: OPTION_TYPE_JSON,
    value: [
        { id: 0, radius: 12, initPosition: { y: "=({%100}-480)" } }
    ]
}
```

Используется в пеналах-гардеробах.

## Система выражений

Динамические размеры задаются строками в формате:

```
"=(<выражение>)"
```

Внутри выражения доступны:
- `{%100}` — текущий размер по соответствующей оси (ширина для x/length, высота для y, глубина для z/depth)
- Арифметические операции: `+`, `-`, `*`, `/`
- Скобки для группировки

**Примеры:**
```
"=({%100}-50)"        →  ширина − 50 мм
"=(({%100}/6)*5)"     →  (высота / 6) × 5
"=({%100}-45)"        →  глубина − 45 мм
```

## Каталожные коды материалов

Коды в поле `corpus.catalogCode` связывают корпус с материальной базой:

| Код      | Описание                          |
|----------|-----------------------------------|
| `N_FOD3` | Основная текстура/цвет 3          |
| `N_FOD2` | Основная текстура/цвет 2          |
| `N_FOD2G`| Вариант с глянцевым покрытием     |
| `N_FOD3G`| Вариант с глянцевым покрытием     |
| `NBM`    | Стандартный материал корпуса      |

## Алгоритм построения 3D-модели

1. **Выбор конфигурации** — по `uid`/`catalogCode` загружается объект описания
2. **Разрешение опций** — пользователь выбирает ширину (radiobutton), остальные параметры — скрытые значения
3. **Подстановка `className`** — рендерер определяет нужный builder-класс
4. **Вычисление выражений** — строки вида `"=({%100}-50)"` вычисляются с подстановкой актуальных размеров
5. **Генерация корпуса** — по `corpus.*` строится основной короб (стенки, дно, верх, задняя стенка)
6. **Добавление компонентов** — итерируются группы `facades`, `legs`, `shelves`, `tabletops`, `aprons`, `plinths`, `corners`, `rods`
7. **Позиционирование** — каждый компонент размещается по `initPosition`, `align`, `margin`, `gap`
8. **Применение материалов** — через `catalogCode` и `id` компонентов подбираются текстуры/материалы
9. **Сборка сцены** — все объекты объединяются в единую 3D-сцену секции
