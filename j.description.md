# Описание файла j.js

## Что это

Минифицированный webpack-бандл (~381 000 строк) — production-сборка большого 3D-планировщика кухни/мебели. Содержит сотни CommonJS-модулей, упакованных по числовым ID.

---

## Основные модули

### Математика и геометрия

**Module 125 — MathHelper**

Базовая 3D-математическая библиотека:

| Функция | Назначение |
|---|---|
| `getLength()` | Расстояние между точками в 3D |
| `getAngle2D()` | Угол между 2D-векторами |
| `getIntersectionPoint()` | Точка пересечения двух линий |
| `projectionPoint2D/3D()` | Проекция точки на прямую |
| `isPointInLine()` | Принадлежность точки отрезку |
| `isPointInsidePolygon()` | Тест вхождения точки в полигон |
| `isLineIntersectPolygon()` | Пересечение линии с полигоном |
| `intersectCircles()` | Пересечение окружностей |
| `intersectLineCirclePoints()` | Точки пересечения линии и окружности |
| `normalizeAngle()` | Нормализация угла к диапазону 0–2π |

### Конфигурация и константы

**Module 9061 — Глобальные константы**

Более 500 определений констант:
- **Типы мебели**: нижние тумбы, верхние шкафы, пеналы, техника
- **Техника**: духовки, посудомойки, стиральные машины, вытяжки, мойки, холодильники
- **Материалы и фасады**: конфигурации покрытий
- **Строительные элементы**: двери, окна, колонны, радиаторы
- **UI/UX**: выравнивание, уровни, группы, позиции
- **Язык**: русский (по умолчанию) / английский
- **Права доступа**: guest, user, manager, admin
- **Цены и каталог**: типы расчётов и конфигураций

## Структура опций юнита

Каждый элемент мебели описывается стандартной схемой:

```
uid          — уникальный идентификатор
catalogCode  — ссылка на каталог
title        — название (русский)
level        — TOP | BOTTOM
width/height/depth — размерные ограничения
options:
  OPTION_TYPE_NUMBER       — числовое поле
  OPTION_TYPE_TEXT         — текстовое поле
  OPTION_TYPE_RADIOBUTTON  — переключатель
  OPTION_TYPE_SELECT       — выпадающий список
  OPTION_TYPE_JSON         — сложные конфигурации
  OPTION_TYPE_HIDDEN_*     — внутренние (невидимые пользователю)
```

## Архитектурные паттерны

1. **Webpack CommonJS** — зависимости между модулями через числовые ID
2. **Константно-ориентированная конфигурация** — весь UI и логика управляются декларативными константами
3. **Декларативное описание UI** — юниты задаются данными, не кодом
4. **Domain-Specific Language** для кухонного домена:
   - *corpus* — корпус тумбы
   - *facade* — дверная панель
   - *plinth* — цоколь
   - *apron* — фартук (скинали)
5. **Модульная система техники** — встраиваемая и отдельностоящая, с типами (`threeBoxes`, `verticalPivotDoor` и т.д.)
6. **Tile-материалы** — поддержка паттернов повторения текстур
7. **Ценовая интеграция** — несколько моделей расчёта, дилерские конфигурации

---

## Итог

`j.js` — это ядро профессионального 3D-планировщика кухни: содержит математику для точного 3D-рендеринга, обширные каталоги материалов и техники, декларативные конфигурации сотен кухонных модулей и многоязычную поддержку.
